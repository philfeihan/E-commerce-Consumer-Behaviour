Analyzing E-commerce Consumer Behaviour and Purchase Intentions📌 Project OverviewThis project analyzes online shopper behavior to predict purchase intentions. By leveraging a dataset of over 12,000 sessions, we identify the key web metrics and seasonal trends that drive successful transactions. The analysis utilizes a weighted logistic regression model to handle class imbalance and achieve high predictive accuracy.👤 AuthorPhil (Fei Han) Completion Date: March 19, 2026 🛠 Tech StackLanguage: R (version 4.5.3) Core Libraries:tidyverse: Data manipulation and visualization.corrplot: Correlation matrix visualization.pROC: ROC curve and AUC calculation.car: Regression diagnostics.📊 Key InsightsPrimary Predictor: Page Values (the average value for a web page) is the strongest indicator of a transaction; higher scores are significantly associated with completed purchases.Seasonality: Conversion rates peak dramatically in November (reaching ~25%), likely due to major sales events, while February shows the lowest engagement.Visitor Dynamics: New visitors exhibit a higher proportion of purchases relative to their session count compared to returning visitors.Behavioral Correlation: High positive correlations exist between administrative and informational page engagement, while exit rates negatively impact the likelihood of purchase.📈 Model PerformanceAlgorithm: Weighted Quasibinomial GLM.Feature Selection: Optimized via Bi-directional Stepwise AIC selection.Evaluation: The final model achieved an AUC of 0.9065, demonstrating excellent discriminative power.📂 Project StructureAnalyzing-E-commerce-Consumer-behaviour-and-Purchase-Intentions.pdf: Full analytical report.online_shoppers_intention.csv: Raw dataset used for analysis.analysis_script.R: Complete R code for data cleaning, EDA, and modeling.How to RunClone the repository:Bashgit clone https://github.com/philfeihan/E-commerce-Consumer-Behaviour.git
